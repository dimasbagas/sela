# Font Sela

Font yang dipakai Sela, di-bundle sebagai woff2 supaya aplikasi tetap jalan offline:

- **Bricolage Grotesque** (700, 800) — judul
- **Archivo** (400, 500, 600, 700) — isi
- **IBM Plex Mono** (400, 500, 600) — angka dan label

Ketiganya berlisensi SIL Open Font License dan bersumber dari Google Fonts.
File woff2 di direktori ini adalah hasil unduhan dari sana, bukan buatan sendiri.
